# ItinerAIry ✈️

An AI-powered travel planning app that generates personalised day-by-day itineraries based on your destination, budget, interests and travel style.

## Tech Stack

### Frontend

- React
- TypeScript
- Vite

### Backend

- Python
- FastAPI
- Pydantic

### AI

- Claude (via AWS Bedrock)

### Database

- PostgreSQL (AWS RDS)

### Cloud Infrastructure

- AWS S3 — static file storage
- AWS CloudFront — frontend CDN
- AWS Lambda — serverless backend
- AWS API Gateway — request routing
- AWS Cognito — authentication

### DevOps

- GitHub Actions — CI/CD pipeline
